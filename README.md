# ✅ To-Do List Web App

A simple and interactive **To-Do List application** built using **HTML, CSS, and JavaScript**, with tasks persisted using browser `localStorage`.

## 🔗 Live Demo
👉 [View the project here](https://neha-tk.github.io/to-do-list/)

## ✨ Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Tasks persist even after page refresh (localStorage)
- Clean and minimal UI

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript (DOM manipulation & localStorage)
